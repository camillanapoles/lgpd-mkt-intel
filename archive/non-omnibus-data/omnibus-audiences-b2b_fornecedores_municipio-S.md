## Pain Points Únicos
1. **Obrigação contratual inesperada**: Empresa entrou no contrato municipal para fornecer serviço de TI/limpeza/saúde, não para ser responsável por proteção de dados. A cláusula LGPD aparece como surpresa no edital e cria urgência imediata.
2. **Sem expertise interna em privacidade**: Não tem DPO real — tem alguém que acumula função. Precisa de solução que entregue o DPO como serviço, não apenas software para um especialista interno operar.
3. **Risco de perder contrato é mais imediato que multa ANPD**: Para o fornecedor, o risco real e imediato é perder o contrato com o município (receita certa) — a multa ANPD é abstrata e futura. A proposta de valor deve ancorar no risco de perda de contrato.
4. **Templates específicos B2G são escassos**: Consultoria genérica entrega documentação para empresa privada, não adaptada para "controlador conjunto com ente público". O fornecedor precisa de documentação que funcione na fiscalização do TCE.
5. **Cross-sell natural do município**: Se o município cliente já usa a plataforma ICT, a indicação para o fornecedor é natural — mas o fornecedor não sabe que o município já contratou. Falta canal de comunicação entre os dois.
