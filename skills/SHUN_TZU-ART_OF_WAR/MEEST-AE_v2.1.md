### 2.3 MSP-1: Segmentação por Critérios Derivados (FDC-U)

#### Critérios de Segmentação Dinâmicos

```
Score_Segmento = Σ [ peso_i × f_i( critério_i ) ]

Critérios de Segmentação (mínimo 6, derivados do contexto):

1. TAM (Total Addressable Market) do segmento
   Peso: 0.20 | f_i: (+)
   "Quantas entidades existem neste segmento?"

2. CAC (Customer Acquisition Cost) estimado
   Peso: 0.15 | f_i: (-)
   "Quanto custa adquirir 1 cliente neste segmento?"

3. LTV (Lifetime Value) estimado
   Peso: 0.15 | f_i: (+)
   "Quanto cada cliente gera ao longo do tempo?"

4. Diferenciação viável (gap do concorrente)
   Peso: 0.15 | f_i: (+)
   "O quanto nossas funcionalidades resolvem dores deste segmento?"

5. Capacidade de execução do time
   Peso: 0.15 | f_i: (+)
   "Temos expertise para atender este segmento?"

6. Velocidade de validação
   Peso: 0.10 | f_i: (+)
   "Quanto tempo para validar demanda neste segmento?"

7. Risco regulatório / mercadológico
   Peso: 0.10 | f_i: (-)
   "Quanta exposição este segmento traz?"

Threshold de seleção: Score >= 6.0 (derivado do contexto)
```

#### Matriz de Segmentação — Template

| Segmento | TAM | CAC | LTV | Diferenc. | Execução | Validação | Risco | **SCORE** |
|----------|-----|-----|-----|-----------|----------|-----------|-------|-----------|
| **[Segmento A1]** | | | | | | | | |
| **[Segmento A2]** | | | | | | | | |
| **[Segmento B1]** | | | | | | | | |
| **[Segmento C1]** | | | | | | | | |
| **[Segmento D1]** | | | | | | | | |

**LEGENDA DE SCORES:**
- 8.0-10.0: Segmento prioritário (atacar primeiro)
- 6.0-7.9: Segmento viável (atacar depois)
- < 6.0: Segmento desfavorável (evitar ou adiar)

### 7.2 Fórmula de Decay Temporal

```
Certeza_atualizada(Carta, t) = Certeza_base × Decay(t) × Corroboração(t)

Decay(t) = 1 / (1 + λ × Δt)
  λ = taxa de decay
    λ = 0.05 → Domínio estável
    λ = 0.15 → Domínio moderado
    λ = 0.30 → Domínio volátil
    λ = 0.50 → Domínio caótico
  Δt = tempo desde última atualização (meses)

Corroboração(t) = 1 + α × (novas_fontes_corroborativas - fontes_contraditórias)
  α = 0.1
```

### 7.3 Regras de Atualização Obrigatória

```yaml
regras_atualizacao:
  - condicao: "Domínio volátil (λ >= 0.30) E Δt > 1 mês"

    severidade: CRITICAL

  - condicao: "Certeza_atualizada < 60%"
    acao: "FLAG: Carta não confiável"
```
