## RESUMO EXECUTIVO

Confidata é uma ameaça REAL e já está executando pivot municipal com conteúdo específico, preços enquadrados na dispensa de licitação e módulos voltados ao setor público.

**A boa notícia:** Confidata tem GAPs exploráveis:
1. Preço ainda alto para micro-municípios
2. Sem DPO-as-a-Service incluído
3. Data Discovery manual, não automatizado
4. Sem anonimização LAI/LGPD
5. Empresa privada COMUM, sem prerrogativas de ICT

**Nossa estratégia:** Atacar os gaps com ofertas que Confidata NÃO pode ou NÃO quer oferecer.

## 1. MATRIZ DE DIFERENCIAÇÃO

### Dimensão 1: Preço e Segmentação

| Segmento | Confidata | CIT AI Tech | Estratégia |
|----------|-----------|-------------|------------|
| **Micro (<10k hab)** | Não atende | R$ 297/mês | Ocasião única |
| **Pequeno (10-20k)** | Starter R$ 497 | R$ 397/mês | 20% mais barato |
| **Médio (20-50k)** | Profissional R$ 1.497 | R$ 597/mês | 60% mais barato |
| **Grande (>50k)** | Enterprise R$ 3.497 | R$ 997/mês | 70% mais barato |

**Insight:** Confidata precifica como B2B corporativo. CIT precifica para realidade municipal.

### Dimensão 2: Valor Entregue

| Componente | Confidata | CIT AI Tech |
|------------|-----------|-------------|
| **Plataforma LGPD** | ✓ (17 módulos) | ✓ (MVP: inventário, riscos, incidentes) |
| **IA Assessora** | ✓ (17 agentes chatbot) | ✓ (AI-DPO Copilot + agentes de descoberta) |
| **DPO Humano** | ✗ (não incluído) | ✓ (DPO dedicado ou compartilhado) |
| **Data Discovery** | ✗ (manual 3 fases) | ✓ (varredura automatizada SQL/NoSQL) |
| **Anonimização** | ✗ (inexistente) | ✓ (tarjamento LAI/LGPD automático) |
| **Setup** | Meses (mapeamento manual) | 15 dias (automação) |
| **Prerrogativas ICT** | ✗ (empresa privada) | ✓ (Art. 75, IV c/d, ETEC, CPSI) |

### Dimensão 3: Enquadramento Legal

| Artigo | Confidata | CIT AI Tech | Vantagem |
|--------|-----------|-------------|----------|
| **Art. 75, II** (dispensa pequeno valor) | ✓ (até R$ 65K) | ✓ (até R$ 65K) | Empate |
| **Art. 75, IV c** (P&D) | ✗ | ✓ (até R$ 390K+) | **CIT +500%** |
| **Art. 75, IV d** (criação protegida) | ✗ | ✓ (software IA) | **CIT exclusivo** |
| **ETEC** (encomenda tecnológica) | ✗ | ✓ (casos complexos) | **CIT exclusivo** |
| **CPSI** (solução inovadora) | ✗ | ✓ (teste + escala) | **CIT exclusivo** |

**Conclusão:** CIT tem enquadramento legal SUPERIOR para contratos maiores.

## 2. PLAYBOOK DE ATAQUE

### FASE 1: MICRO-MUNICÍPIOS (MAI-JUN 2026)

**Público-alvo:** 1.000 municípios <10k habitantes (19,8% com responsável LGPD)

**Oferta Municipal Lite:**
- Preço: R$ 297/mês (R$ 3.564/ano)
- Inclui: Plataforma básica + DPO compartilhado (1 DPO para 10 municípios)
- Setup: 15 dias
- Enquadramento: Art. 75, II (dispensa)

**Argumentário:**
- "Confidata parte de R$ 497/mês. Nós oferecemos solução completa por R$ 297/mês."
- "DPO dedicado custaria R$ 5-10K/mês. Nós incluímos DPO compartilhado."
- "Setup em 15 dias vs meses de mapeamento manual."

**Mecanismo de Go-to-Market:**
1. Listar top 100 micro-municípios por estado (PI, MA, SE, etc.)
2. Abordagem direta via prefeituras + consórcios
3. Webinar "LGPD para pequenos municípios: como se adequar com R$ 300/mês"

### FASE 2: CONSÓRCIOS (JUL-SET 2026)

**Público-alvo:** Consórcios intermunicipais (tipo CIMINAS)

**Oferta Consórcio Pack:**
- Preço: R$ 197/mês por município
- Volume mínimo: 10 municípios
- White-label: Consórcio pode revender com própria marca
- DPO dedicado: 1 DPO para cada 20 municípios

**Argumentário:**
- "Confidata não tem modelo de volume. Nosso preço cai com escala."
- "Consórcio pode revender como solução própria, gerando receita."
- "Prerrogativas ICT permitem contratação direta sem licitação complexa."

**Mecanismo de Go-to-Market:**
1. Mapear top 20 consórcios por estado
2. Proposta de parceria com revenue-share
3. White-paper técnico sobre enquadramento ICT para consórcios

### FASE 3: DIFERENCIAÇÃO TÉCNICA (OUT-DEZ 2026)

**Foco:** Data Discovery + Anonimização

**Lançamento:**
1. **Data Discovery Express:** Varredura automatizada de bancos SQL/NoSQL
   - Identificação de CPFs, dados sensíveis
   - Inventário técnico em 48 horas
   - Relatório de calor de riscos

2. **Anonimização LAI:** Tarjamento automático de documentos
   - Processamento de PDFs e diários oficiais
   - Conformidade com Acórdão TCE-PR 1153/2025
   - API para integração com sistemas de ouvidoria

**Argumentário vs Confidata:**
- "Confidata mapeia manualmente. Nós escaneamos automaticamente."
- "Confidata não tem anonimização. Nós resolvemos o gargalo LAI/LGPD."
- "Confidata documenta. Nós automatizamos."

### Roteiro 1: "Confidata é caro demais"

**Cliente:** "Confidata custa R$ 497/mês, está fora do orçamento."

**Resposta CIT:**
```

(20% mais barato) E inclui DPO dedicado - algo que Confidata não oferece.

Além disso, nossa tecnologia de Data Discovery automatiza o inventário em dias,
enquanto Confidata demanda meses de mapeamento manual.

Posso mostrar uma demo em 15 minutos?
```

### Roteiro 2: "Confidata tem mais módulos"

**Cliente:** "Confidata tem 17 módulos, vocês têm menos."

**Resposta CIT:**
```
É verdade. Confidata tem mais módulos, mas muitos são irrelevantes para municípios:
- Transferências internacionais (não se aplica)
- Programas de integridade corporativa (não é prioridade)

Nós focamos no que MATRIA para prefeituras:
✓ Data Discovery automatizado (Confidata não tem)
✓ Anonimização LAI/LGPD (Confidata não tem)
✓ DPO-as-a-Service incluído (Confidata não tem)
✓ Prerrogativas ICT (Confldata NÃO pode oferecer)

Prefiro profundidade no essencial que breadth no irrelevante.
```

### Roteiro 3: "Já temos Confidata"

**Cliente:** "Já contratamos Confidata."

**Resposta CIT:**
```
Ótimo escolha. Confidata é excelente para DOCUMENTAÇÃO.

Mas vocês ainda têm dois gargalos:
1. Data Discovery manual - alguém precisa mapear tudo
2. DPO - a plataforma não atende solicitacoes de titulares

Nós podemos COMPLEMENTAR Confidata:
- Data Discovery para popular o inventário automaticamente
- DPO-as-a-Service para operacionalizar o dia a dia
- Anonimização para resoLver o gargalo LAI

Ou, se preferir, podemos migrar tudo para nossa plataforma com desconto.
```

**Resposta CIT:**

```
Justificativa TÉCNICA:

Justificativa ECONÔMICA:

Justificativa ESTRATÉGICA:
- Confidata é empresa privada COMUM

- Dispensa Art. 75 IV c/d até R$ 390K+ (vs R$ 65K Confidata)

Posso preparar uma memoria comparativa para sua procuradoria?
```

## 6. RISCOS E MITIGAÇÃO

### Risco 1: Confidata abaixar preços
**Probabilidade:** Alta (6-12 meses)
**Impacto:** Médio

**Mitigação:**
- Fixar clientes em contratos anuais
- Diferenciar por DPO incluído (Confidata não pode replicar facilmente)
- Ancorar em prerrogativas ICT (Confldata NÃO pode copiar)

### Risco 2: Confidata desenvolver data discovery
**Probabilidade:** Média (12-18 meses)
**Impacto:** Alto

**Mitigação:**
- Liderança emanonimização LAI (Confidata não mencionou)
- Data Discovery especializado em sistemas governamentais (Protheus, SGP, etc.)
- DPO-as-a-Service como barreira de entrada

### Risco 3: Confidata buscar certificação ICT
**Probabilidade:** Baixa (requer mudança de estrutura jurídica)
**Impacto:** Alto

**Mitigação:**
- Construir relacionamento com consórcios ANTES de Confidata
- Casos de sucesso públicos usando prerrogativas ICT
- Artigos técnicos sobre enquadramento Art. 75 IV
